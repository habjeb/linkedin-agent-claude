# Onboarding (first run)

Run this only when no config exists in the registry. Keep it short: two required questions, a few optional ones with sensible defaults. Ask in the user's language.

## Required

1. **Who are you targeting?**
   Sector or type of prospect, decision-maker role, geography.
   Example answers: "padel clubs in France, Switzerland and Belgium, owners or managers", "independent bakeries in the Lyon area", "HR directors at 50-500 employee SaaS companies in Germany".

2. **What do you offer them?**
   One or two sentences, or a link to the website, or an attached brochure/PDF. If the user gives a link or a file, read it and write a two-sentence summary yourself, then confirm it with the user.
   Also ask whether there is a secondary offer to mention only when relevant (example: "a booking app first, and a website redesign if their site needs it").

## Optional (propose defaults, let the user override)

| Setting | Default | Notes |
|---|---|---|
| Sender name and role | Read from the LinkedIn profile in phase 1 | Used to keep notes in first person |
| Brand to mention in notes | The offer's product or company name | Some users want a product brand only and never their company name; ask |
| Note language | The prospect's language (French for France, Belgium-Wallonia, Romandy; German for German-speaking Switzerland, etc.) | |
| Tone | Professional, direct, informal "vous" in French | |
| Session cap | 20 invitations per session per account | Warn once above 25 |
| Exclusions | None | Companies, people or domains never to contact (current clients, competitors, partners) |
| Things never to say | None | Example: never name the prospect's current software, never mention prices |
| Team members | Just the user | Names of other people who prospect from their own LinkedIn account with the same registry |

## Save

Write the answers to the registry config (see `references/registry.md`), then show a five-line summary:

```
Target: padel clubs, FR / CH / BE, owners or managers
Offer: club management app (bookings, POS, marketing), no booking commission
Secondary offer: website creation or redesign, only if their site needs it
Notes: French, first person, product brand only
Cap: 20 per session
```

On later runs, show this summary in one line and move on. If the user wants to change something, update the config and keep going.
